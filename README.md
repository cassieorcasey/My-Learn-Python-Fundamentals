# python-fundamentals-data-science

Repositori catatan belajar, latihan kode, dan mini-skrip untuk menguasai fondasi Python yang relevan dengan alur kerja Data Science.

Fokus repositori ini bukan mempelajari seluruh fitur umum Python, melainkan sintaksis dan logika pemrograman yang paling sering dipakai saat membersihkan, memproses, dan menganalisis data.

## Fokus Materi

Materi disusun bertahap dari pemahaman sintaks dasar hingga logika pengolahan data terstruktur:

1. **Sintaksis & Tipe Data Dasar**
   Tipe data primitif (integer, float, string, boolean), operasi aritmatika, casting tipe data, dan manipulasi string.

2. **Struktur Data Bawaan (Built-in Data Structures)**
   Operasi list, tuple, dictionary, dan set. Penggunaan list comprehension dan dict comprehension untuk transformasi koleksi data.

3. **Kontrol Alur (Control Flow)**
   Percabangan kondisional (`if`, `elif`, `else`) dan iterasi (`for`, `while`). Teknik iterasi menggunakan `enumerate()` dan `zip()`.

4. **Fungsi & Modularitas**
   Definisi fungsi, default arguments, `*args`, `**kwargs`, lambda function, dan pembagian kode ke dalam modul terpisah.

5. **Penanganan Error & File I/O**
   Penggunaan blok `try-except` untuk menangani exception, serta pembacaan dan penulisan file teks maupun format CSV tanpa pustaka pihak ketiga.

6. **Logika Algoritma Dasar untuk Analisis**
   Latihan pemrosesan tabel data sederhana, agregasi manual (menghitung rata-rata, filtering baris, pivoting sederhana), dan validasi input.
